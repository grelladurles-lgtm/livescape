# LIVESCAPE

**Tu mundo. Tu historia. Tu forma de vivirla.**

Livescape es una red social de roleplay diseñada como una plataforma social normal: perfiles, publicaciones, historias, amigos y mensajes.

**No utiliza fichas de personaje.**

## Incluye
- Frontend responsive
- Backend Express
- PostgreSQL
- Registro / login
- Perfiles
- Feed
- Publicaciones
- Comentarios
- Reacciones
- Amigos
- Mensajes privados
- Bloqueos y reportes
- Búsqueda
- Arquitectura preparada para producción

Consulta `docs/SETUP.md` para ejecutarlo.
